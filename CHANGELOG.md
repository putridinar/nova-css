# Changelog

All notable changes to NOVA CSS will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-15

### Added
- Complete CSS architecture with CSS Layers (reset, tokens, utilities, components)
- Design token system with CSS Custom Properties
- Color palette with 7 color scales (50-950)
- Semantic color tokens for light and dark modes
- Typography scale (xs through 6xl)
- Spacing scale (0 through 64)
- Border radius tokens
- Shadow elevation system
- Transition tokens
- Z-index scale
- Container system
- Display utilities (block, flex, grid, hidden, etc.)
- Flexbox utilities (direction, alignment, justify, gap)
- Grid utilities (cols, span)
- Spacing utilities (margin, padding, gap)
- Typography utilities (size, weight, family, alignment)
- Color utilities (text, background, border)
- Border utilities (width, radius)
- Shadow utilities
- Position utilities
- Width/height utilities
- Responsive breakpoint utilities (sm, md, lg, xl)
- Dark mode support (light, dark, system)
- CSS Reset (non-aggressive)
- Button component (7 variants, 5 sizes)
- Button Group component
- Input component (with error states)
- Textarea component
- Select component
- Checkbox & Radio components
- Switch component
- Label component
- Card component (header, body, footer)
- Badge component (7 variants)
- Alert component (5 variants)
- Avatar component (4 sizes)
- Table component
- Progress component
- Skeleton loading component
- Spinner component
- Divider component
- Tabs component
- Accordion component
- Breadcrumb component
- Pagination component
- Navbar component
- Sidebar component
- Tooltip component
- Modal/Dialog component
- Toast component
- Dropdown component
- Form group component
- Code block component
- Accessibility utilities (sr-only, focus-visible)
- Dark mode documentation
- Theming documentation
- Interactive playground
- Complete documentation website

### Technical
- CSS Layers architecture for proper cascade control
- CSS Custom Properties for all tokens
- CSS logical properties for internationalization
- Modern CSS features (color-mix, nesting-ready)
- Mobile-first responsive design
- WCAG 2.2 AA accessibility targets
- Reduced motion support
- TypeScript type definitions
- Framework-agnostic core CSS
